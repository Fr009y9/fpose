Trợ lý AI Phân tích Hình ảnh (Gemini API)

Chưa cấu hình
Hướng dẫn lấy Gemini API Key miễn phí (mất ~1 phút):
  1. Truy cập Google AI Studio tại đường dẫn mở tab mới: https://aistudio.google.com/ và đăng nhập bằng tài khoản Google[cite: 1].
  2. Chọn mục Get API key ở thanh menu bên trái -> bấm Create API key[cite: 1].
  3. Sao chép đoạn mã bắt đầu bằng AIzaSy... và dán vào ô phía trên, sau đó bấm Lưu Key[cite: 1].
  4. Bảo mật: API Key chỉ được lưu cục bộ trên trình duyệt của bạn (localStorage), hoàn toàn không gửi đi bất kỳ máy chủ trung gian nào[cite: 1].
Backup & Restore

Xuất / Nhập dữ liệu JSON

Hướng dẫn sử dụng tính năng Backup:
  • Xuất bản sao lưu (Export JSON): Đóng gói toàn bộ Blob WebP, EXIF, phân tích ánh sáng, thẻ dáng và Shot List thành 1 tệp .json duy nhất.
  • Khôi phục dữ liệu (Import JSON): Chọn tệp sao lưu để khôi phục toàn bộ dữ liệu vào IndexedDB mà không làm giảm chất lượng ảnh.
